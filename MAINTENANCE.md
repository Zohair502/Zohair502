# Profile maintenance

This is a GitHub profile README, not a separately hosted website. GitHub controls the page background, fonts, navigation, sidebar, contribution calendar, and account avatar. The README uses supported Markdown, HTML tables, picture sources, and SVG images. SVG styling is contained within the image. It has no JavaScript, custom page CSS, or simulated interactive tabs.

## Assets and facts

- `assets/portrait-original.png` is the user-uploaded black-shirt photograph, copied without changing any bytes. Both hero SVGs embed that same PNG. Their vector frames only position, scale, and clip the original; no facial pixels are generated or retouched.
- `assets/dont-let-it-fall-artwork.jpg` is existing project promotional artwork, copied unchanged. `assets/game-cover.svg` displays it in a wide frame. It is explicitly not presented as a gameplay screenshot.
- InnoTravel has a verified public repository, but it was empty at implementation time. Its preview is a labeled text placeholder.
- Accounting and Automation use labeled editorial placeholders. No client screens, source, data, credentials, or invented project links are included.
- The mockup's numbers, project technology labels, website, social links, and recent activity were not treated as factual evidence. The game uses Defold/Lua, not the Unity/C# text in the generated concept.

## Daily update

`.github/workflows/profile.yml` refreshes statistics and the contribution snake at 06:17 UTC each day, on manual dispatch, and after relevant source changes. All external Actions are pinned to commit SHAs. The built-in repository token is used only for the contribution calendar and publishing assets. No personal access token is required.

The statistics fetch is intentionally unauthenticated and reads only the public GitHub REST API. It paginates all owned public repositories. Repository counts include public forks; original repository counts exclude them. Stars and received forks are summed only over original public repositories. No contribution totals, streaks, ranks, or activity are invented. The card includes its last successful update time; failures leave previous assets intact.

The snake is generated by Platane/snk from GitHub's contribution calendar. It adds no contributions. Future API outages or Actions failures can leave the last successful image in place; consult the linked workflow status. SVG animation may appear static in clients that do not animate SVGs.

Run `python -m unittest -v test_profile.py` for local validation and `python update-profile.py` for a live public statistics refresh. Verify any future screenshots for sensitive client information before adding them. A separate interactive website would be needed for custom page layout, real tabs, hover effects, and interactive 3D; none is deployed here.
